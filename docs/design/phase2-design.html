1剧集列表：正序 / 倒序切换 可落地·零风险

现状：Emby 原生剧集固定升序（S01E01 在最左），新更新的集要滑到最右，反直觉。

方案：给头像绑 contextmenu，弹出与原生同风格的菜单，动作直接走 Emby 路由。

4JAV 同系列影片墙（复用名称映射）可行·有取舍

数据源已摸清：AVDB 返回的影片详情里自带 series（系列 ID + 名称）与 relative_movies（同系相近影片，带封面）。
结论：可做，且零额外请求。但 AVDB 没有「按系列列片」的接口（只有系列元数据），所以我们的策略是：
① 影片墙 = 详情里的 relative_movies；② 「查看更多」外链 JavDB 系列页 /series/{id}；③ 名称映射沿用演员那套（简/繁/日文自动匹配 + 过滤）。

8JAV 外部站点：从 8 个扩到 16+ 可落地·配置化
