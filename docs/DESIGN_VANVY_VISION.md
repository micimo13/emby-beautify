## 一、现状盘点：我们已有 4 款轮播

| # | 现有轮播 | 布局本质 | 优点 | 缺点 |
|---|---------|---------|------|------|
| 1 | banner_classic (Misty 经典) | 全屏背景 + 左侧信息 | 经典耐看 | 大屏信息占比小，略显单调 |
| 2 | banner_fluent (Fluent) | 全屏背景 + 信息区 + 透明顶栏 | 现代简洁 | 无右侧联动，沉浸感一般 |
| 3 | banner_carousel (Banner图) | 横幅图轮播 | 轻量 | 无信息展示 |
| 4 | banner_homeswiper (封面流) | 左侧主图 + 右侧缩略图流 | 交互最强 | 代码 292KB 庞大，样式偏工具感 |

**共同短板**：都缺少「品牌感」和「情绪渲染」——它们是在"展示内容"，而不是在"营造氛围"。

## 二、美术总监：3 款原创设计方向

### 🏆 设计A：AURORA · 极光沉浸式（推荐首选）
**视觉语言**：动态极光光晕（conic-gradient + blur + 旋转动画，呼吸感）+ 深蓝紫渐变天空 + 左侧 Logo/评分胶囊/标题/双按钮 + 右侧封面流缩略图联动 + 底部渐变进度条。

**为什么首选**：
- 「光」的情绪渲染最强，一眼看出是自研品牌（区别于所有现款）
- 保留封面流联动（交互优势不丢）
- 桌面端信息层级：Logo → 评分标签 → 标题 → 简介 → 按钮，黄金左侧位
- 手机端自动隐藏缩略图侧栏、精简简介，不拥挤

### 设计B：SPLIT · 分屏新视界
**视觉语言**：左 58% 竖版大图海报 + 右 42% 毛玻璃信息面板 + 网格光效分割线 + 杂志式排版（kicker 眉题 + 标题 + 评分 + 芯片标签）。

**定位**：信息密度最高，适合"想快速了解影片"的用户。移动端上下堆叠（海报在上、信息变底部抽屉），平板自适应。

### 设计C：CINEMA · 影院黑金
**视觉语言**：21:9 超宽画幅 + 上下影院黑边 + 黑金配色 + 金色光影 + 底部胶片帧条 + 「放映」按钮。

**定位**：最强仪式感，黑金奢华。适合追求"进影院"感觉的用户。但 21:9 在黑边内显示，实际有效面积小于前两款。

## 三、前端工程师：技术可行性评估

### 完全可行，且成本可控 ✅

**核心结论：三款设计 95% 用现有技术栈即可实现，无新技术风险。**

| 技术点 | 方案 | 风险 |
|--------|------|------|
| 轮播引擎 | 复用现有 Swiper（homeSwiper 已内嵌）/ 或自写轻量 fade 轮播 | 🟢 零风险 |
| 动态光晕 | CSS conic-gradient + filter:blur + @keyframes 旋转 | 🟢 纯 CSS，性能好 |
| 毛玻璃面板 | backdrop-filter（Emby 4.9 已大量使用） | 🟢 兼容 |
| 封面流缩略图 | 复用 homeSwiper 的缩略图联动逻辑 | 🟢 已验证 |
| 响应式 | CSS clamp() + 媒体查询（设计稿已按 3 断点验证） | 🟢 设计稿已过 |
| 数据 | 复用 carousel-rules 策展查询（Types/Sort/Limit/Pin） | 🟢 现成 |
| 图片 | Backdrop maxWidth 1920（大屏清晰）+ Logo maxWidth 500 | 🟢 现成 |

### 关键设计决策（开发时注意）

1. **命名空间**：全部 `vanvy-banner-*` 前缀，与现有 4 款零冲突（manifest 互斥机制已就位，作为第 5/6/7 款 style 可选）
2. **性能铁律**：
   - 光晕动画用 `transform/opacity`（GPU 加速），不用 `filter` 动画（重绘）
   - 背景图 `maxWidth: 1920`，防止 4K 大图卡顿
   - 缩略图懒加载（IntersectionObserver 或 Swiper 自带）
3. **降级方案**：`backdrop-filter` 不支持时回退纯色渐变（无 JS 判断，CSS @supports 即可）
4. **移动端策略**（设计稿已验证）：
   - 手机：隐藏缩略图侧栏/胶片帧条（display:none），简介限制 2 行，按钮收紧
   - 平板：缩略图减至 2-3 个，字号用 clamp 自适应
5. **兼容 4.8/4.9**：所有选择器走 `view:not(.hide) .section0` 标准挂载点，与现有款同构

### 开发量估算

| 设计 | JS 改造 | CSS | 合计 |
|------|:---:|:---:|:---:|
| AURORA | 中（复用封面流联动） | 大（光晕系统） | ~2-3h |
| SPLIT | 小（信息面板重组） | 中 | ~1.5-2h |
| CINEMA | 小（黑边+胶片帧） | 中 | ~1.5-2h |

## 四、结论与建议

### 可行性：✅ 高，值得开发

**建议路线**：
1. **首选开发 AURORA** —— 视觉差异化最强（动态光晕=独家记忆点），且封面流联动复用现成逻辑，性价比最高
2. SPLIT / CINEMA 作为后续可选款，按主人喜好补充
3. 每款都做成独立 style 组件，与现有 4 款并列可选（安装器自动支持，零侵入）

**一句话**：我们已有 4 款"别人家"的轮播，AURORA 将是我们第一款"自家"的轮播——用光晕做情绪，用封面流做交互，用 clamp 做全设备适配。
