① 快速开始

三种方式，任选其一。

方式 A · 在线一键安装（最省事）

curl -sL https://raw.githubusercontent.com/micimo13/emby-beautify/main/online-install.sh | bash

会自动下载 → 探测你的 Emby → 弹出交互向导，一步步问你。

⚠️ 关于「无人值守」：本脚本不会替你猜。若当前没有可交互终端 （例如写进 CI、或某些面板里执行），它会明确中止并提示用法，绝不会静默安装。 要无人值守请显式指定： 
curl -sL https://raw.githubusercontent.com/micimo13/emby-beautify/main/online-install.sh | bash -s -- \
  --container emby --features 1,2,3,4,5,6,7,8 --theme blackgold --yes
另外：只认真正的 Emby 容器（名字里带 emby 的其它容器会被拒绝）。

方式 B · 交互向导（想要更多控制）

tar xzf ves.tar.gz && cd ves-*
bash install-ves.sh

方式 C · 一条命令直装（老手）

bash install-ves.sh --container emby \
  --features 1,2,3,4,5,6,7,8 \
  --theme blackgold \
  --bstyle wave --lstyle cinema \
  --frost weak --perrow 6 --yes

方式 D · 连外部后端一起装（最完整）

需要 JAV 增强 / TMDB 资料增强？先把配套服务拉起来，再装美化：

🖼 LOGO 怎么配置

加载页 LOGO 与 浏览器标签图标（favicon） 是两项独立设置，引导向导会分别问你。

# ① 加载页 LOGO：本地文件 或 图片 URL（两种都行）
bash install-ves.sh --container emby --features 1 --logo /path/我的logo.png
bash install-ves.sh --container emby --features 1 --logo https://img.example.com/logo.png

# ② 浏览器标签图标：单独指定（png / ico / jpg / svg，同样支持 URL）
bash install-ves.sh --container emby --features 1 --favicon https://img.example.com/tab.png

# ③ 不要加载页 LOGO（只显示文字 + 进度线）
bash install-ves.sh --container emby --features 1 --no-logo

# ④ 不替换浏览器标签图标（保留 Emby 自带）
bash install-ves.sh --container emby --features 1 --no-favicon

# ⑤ 调加载页 LOGO 显示宽度
bash install-ves.sh --container emby --features 1 --logo-width 240
给定 URL 时会自动下载（带图片魔数校验，下载到 HTML/404 页会拒绝并降级）； 内网环境下载失败可先设 VANVY_PROXY_URL 走代理（HTTP/SOCKS5）。
注意：加载页 LOGO 与浏览器标签图标是两项独立设置，分别填。

或者放进约定目录（按容器名匹配，多台机器各自不同 LOGO）：

components/loading/vanvy/
├── logo/brand.png          ← 通用加载页 LOGO（所有容器共用）
└── logos/
    ├── emby-302/brand.png  ← 仅 emby-302 使用（优先级更高）
    ├── emby-302/favicon.png← 仅 emby-302 的浏览器标签图标
    └── emby-18/brand.png
    （favicon.png 不放会自动用同目录 brand.png 生成）
建议：透明底 PNG，宽度 400–800px，高度别超过 200px；标签图标 128×128 即可。
不提供也完全没问题 —— 加载页只显示文字和进度线，标签图标保留 Emby 原样，不会报错。

⚡ 更省事：一键构建这些服务（推荐）

不想手动找镜像/配数据库？用内置的构建器，docker compose 一键拉起 （各自带独立数据库，不碰你已有的容器和库）：

# 交互式（会问你代理、端口）
bash components/external/install-external.sh

# 或一条命令：同时装 AVDB + MetaTube，并给出地址
bash components/external/install-external.sh --avdb --metatube \
  --proxy "http://192.168.1.10:1082" --yes

# 其他：
bash components/external/install-external.sh --status          # 看状态
bash components/external/install-external.sh --uninstall       # 停容器（留数据）
bash components/external/install-external.sh --uninstall --purge   # 连数据一起删

装完把打印出的地址填给美化安装器即可（写 --avdb / --metatube， 或在向导里选「本机一键构建」会自动回填）。容器名： vanvy-avdb / vanvy-metatube（各带一个 *-db）。

提示：AVDB 首次启动要初始化数据库，约 1–2 分钟，属正常现象。

🧩 JAV 增强需要哪些服务

装了 JAV 增强后，若想让页面显示番号 / 演员 / 标签 / 短评 / 外链，需要这些服务：

服务用途填写格式（务必带协议头）去哪拿
MetaTube JAV 元数据：番号 / 演员 / 标签 / 发布日期 / 封面 http://192.168.1.10:28080
内网 IP 直接填，端口按你实际部署的		 github.com/metatube-community
（Emby/Jellyfin 刮削服务）
AVDB 引擎 JavDB 搜索 / 短评 / 剧照图片解码 http://192.168.1.10:38000
＋ 配套 API Key（形如 9a60dc…）		 你所用的 JavDB 数据引擎后台
连接器
（即图片代理）		 一服务解决三件事：图片（图床被墙时转发）· 预告片（直链媒体透传）· TMDB（API 代理） https://你的域名/vdimg 一键部署：install-ves.sh --imgproxy
（自建 Nginx / CDN 反代，可留空）
🎯 只想填一个代理？
连接器（图片代理服务）现在同时提供三条路：
· /i?u=<图片地址> ---- 图片代理
· /p?u=<媒体地址> ---- 通用透传：预告片等直链媒体走它，浏览器自己不必能出网
· /tmdb/<path> ---- TMDB API 代理：服务端持 Key + 走代理，外网也能用资料增强
所以通常只需要给它配一个出网代理（HTTP / SOCKS5）， 图片、预告片、TMDB 就全通了。
填写要点
· 地址必须带 http:// 或 https:// 前缀
· 内网服务直接填内网 IP（例 http://192.168.1.10:28080）
· 不确定能不能连通？先留空安装，之后再编辑容器内 vanvy-detail/config.js 补上即可
· 向导里有简单格式校验，不像 URL 会提示你

🈶 演员名对不上？（简体 ⇄ 繁体/日文）

本地 Emby 演员名可能是简体（如 弥生美月），JavDB 上却是繁体/日文 （彌生美月 / 弥生みづき）。默认全自动处理： 搜演员 → 取官方名 + 别名 → 逐个试搜作品 → 选标题命中最高的那个名。

本地名自动解析为JavDB 演员页作品
弥生美月弥生みづき/actors/Jekq21 条 ✅
三上悠亚三上悠亜/actors/Av2e11 条 ✅
桥本有菜（已改名）新ありな/actors/RJM822 条 ✅

想手动指定（优先于自动）：

VANVY_ACTOR_ALIAS='{"弥生美月":"弥生みづき","三上悠亚":["三上悠亜","三上悠亞"]}' \
  bash install-ves.sh --container emby --features 5 --theme blackgold --yes
自动结果会缓存在浏览器 localStorage（key vanvy:actorAlias:v1），第二次打开秒出。
完全不想折腾？
直接一路回车跳过。JAV 页面会显示 Emby 本地已有的信息（标题、海报、简介）， 只是拿不到番号/演员/短评这类增强数据。其它 5 个模块完全不受影响。

📧 TMDB 资料增强（可选）

轮播不需要 TMDB（评分/年份直接取 Emby 本地数据）。
详情页「资料增强」（剧照 / 预告片 / 更多类似 / 演员）需要 TMDB： 申请免费 Key：themoviedb.org/settings/api， 用 --tmdb-key <KEY> 传给连接器即可。

外网也能用：Key 存在连接器服务端，请求由它带出去（走你配的代理）， 所以即使你在外网、浏览器本身没挂代理，资料增强照样有数据。
③ 连接器（图片代理 / 预告片 / TMDB）

🖼 图片代理：也可以手动搭（零依赖）

向导选 [2] 时，它会自动跑下面这套；也可手动执行：

# ① 自检（不动系统，先看链路通不通）
cd components/imgproxy
bash install-imgproxy.sh --check

# ② 有代理就这样装（把代理地址换成你自己的；HTTP/SOCKS5 都支持）
sudo bash install-imgproxy.sh --systemd \
     --proxy "socks5h://用户名:密码@你的代理:1080" \
     --mode auto

# ②' 没有 systemd / 想用 docker 容器跑
sudo bash install-imgproxy.sh --docker \
     --proxy "http://用户名:密码@你的代理:8080" --mode auto

# ③ 没有代理（图床本身能直连）
sudo bash install-imgproxy.sh --systemd --mode none

然后在 nginx 里加一段反代（片段见 components/imgproxy/nginx-vdimg.conf）， 装的时候填：

③ 图片代理地址：https://你的域名/vdimg

代理怎么填

写法说明推荐
socks5h://用户:密码@主机:端口SOCKS5，DNS 由代理解析（防污染）⭐ 推荐
socks5://用户:密码@主机:端口SOCKS5，本机解析 DNS可用
http://用户:密码@主机:端口HTTP 代理可用

多个代理用逗号分隔，前一个挂了自动试下一个。

三种模式

模式行为
none从不走代理，全部直连
auto（默认）只有墙外域名（YouTube / DMM 等）走代理，省流量更快
all所有请求都走代理
验证是否成功：浏览器打开
https://你的域名/vdimg/i?u=https%3A%2F%2Fi.ytimg.com%2Fvi%2F_TRSvK-Omwc%2Fhqdefault.jpg
能看到图片就对了。也可以访问 /healthz 看当前配置。
不想搭？直接留空
留空 = 直接用原图地址。少数图（JavDB 封面 / YouTube 缩略图）不显示， 其它 5 个模块完全不受影响。

⑥ 常见问题

装完没变化？

浏览器 Ctrl+F5 强制刷新。 仍无变化 → docker exec <容器> grep -c vanvy /system/dashboard-ui/index.html，看是不是 0。

Emby 升级后美化没了？

正常 —— 升级会覆盖 index.html。用持久化工具一条命令恢复：

bash scripts/ves-persist.sh save    --container emby   # 部署后先备份
bash scripts/ves-persist.sh restore --container emby   # 升级后恢复

加载页一直不消失？

它会等轮播就绪，最长 12 秒强制淡出（内置兜底）。若一直卡 → 检查轮播是否装成功。

JAV 页面没有番号/演员？

未配 MetaTube。见 第 ⑤ 节（可用一键构建拉起）。

外网访问时「资料增强 / 剧照 / 预告片」没了？

多半是后端地址填的是内网 IP。本套件已做适配：内网访问→内网优先（快）， 外网访问→自动跳过内网地址，只用公网 /enrich · /avdb · /vdimg。 请确保这些公网出口可访问（见 第 ⑤ 节 的连接器）。

执行安装脚本时需要交互吗？会不会自动给我装了？

不会。脚本只从终端读答案；拿不到就中止，不会用默认值蒙。 无人值守请显式传 --container 与 --yes。

支持群晖 / 裸机 Emby 吗？

目前只支持 Docker 部署的 Emby。

影响我原有数据吗？

不影响。只在容器内追加 vanvy-* 目录 + 修改 index.html， 不碰媒体文件、不改数据库；--uninstall 可完整还原。

多台 Emby 能一起装吗？

可以，逐台执行 --container <各自容器名>。

想卸载？

bash install-ves.sh --container emby --uninstall
